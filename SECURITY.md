# Security

## Supported versions

Only the latest release gets security fixes. If you're on an older one, update first and check whether the problem is still there.

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately instead, with GitHub's [Report a vulnerability](https://github.com/Lil-Pink/dawsome/security/advisories/new) form (the same button is on the Security tab). The report stays between you and me until a fix is out.

A few lines are plenty: what you did, what happened, the Dawsome version, and Linux or Windows. If a project file, sound file or plugin sets it off, attach it or say which one.

## What to expect

Dawsome is made by one person (me) in my spare time, so there's no set response time, but I read every report. A confirmed problem gets fixed in the next release, and its notes say what was fixed. If you'd like credit, say so and you'll be named in the advisory.
